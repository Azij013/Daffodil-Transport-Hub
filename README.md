🚍 DIU Transport Hub (DTH)
📌 Project Overview

The DIU Transport Hub (DTH) is a web-based application designed to modernize and simplify university transportation services. It allows students and faculty members to easily access transport-related information such as bus schedules, routes, and (planned) live tracking.

This project aims to reduce manual processes and improve convenience through a structured digital system.

⚠️ Note: This repository currently contains only the frontend implementation of the system.

🎯 Project Objective

The main goal of this project is to build a user-friendly platform that:

Digitizes ticket booking and transport management
Provides clear access to bus schedules and routes
Differentiates services for students and faculty
Enhances overall user experience
